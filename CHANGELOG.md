# Changelog

## 0.1.0 · 2026-11-18

- Initial GKIA Assistente public companion module.
- Sequential named-handler orchestration with a 50-task limit.
- Recoverable failure reporting, optional continue-on-error and pre-task cancellation.
- Status-only progress events, educational example and automated Node.js tests.
- Documentation in English and Portuguese, security policy and GitHub Actions CI.

This is a **new public educational component**, not a publication of the private GKIA runtime.
