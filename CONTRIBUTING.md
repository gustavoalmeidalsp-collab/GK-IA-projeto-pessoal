# Contributing · GKIA Assistente

Thank you for your interest! This is a small public learning module, not the private GKIA application.

1. For a significant change, open an issue explaining the problem.
2. Create a focused branch and pull request with a short rationale.
3. Use Node.js 20 or newer; run `npm run check`, `npm test` and `npm run example`.
4. Include tests for behavioral changes, and keep new dependencies to a minimum.
5. Never add passwords, private keys, customer records, client software or source from the private GKIA project.
6. Be respectful and give concrete, constructive feedback.

Maintainer response times are not guaranteed.
