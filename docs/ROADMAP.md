# GKIA public module roadmap

**Available now (v0.1.0):** named handlers, bounded sequential tasks, controlled errors, cancellation between tasks, status-only events, example and tests.

**Potential next improvements:**
- Additional examples and TypeScript types.
- Cooperative per-task timeout contracts.
- Optional sanitized checkpoints.
- More thorough testing, coverage and contributor feedback.
- A small accessible educational demo.

These are ideas, not promises or claims of implementation.

**Boundary:** The private GKIA Assistente system and client applications remain in private repositories. New public work must be independently reviewed for security, privacy and permission to publish.
